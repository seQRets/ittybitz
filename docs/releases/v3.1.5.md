# v3.1.5 🦕 Stegosaurus — tidier notices

A small follow-up to [v3.1.4](v3.1.4.md). The cryptography of the app and the
Recovery tool is unchanged.

## Changes

- **Cleaner notices at the top of the page.** The "New in 3.1" notice, the
  offline tip, and the notice for the old installed app now read left to
  right in the same column as the page, with the download link on its own
  line beneath the text. The close button is a larger X in the banner's
  top-right corner, inside a rounded box. The green-to-amber gradient is
  replaced by a flat tint.
- **Closing a notice keeps it closed.** Closing "New in 3.1" used to let the
  separate "run IttyBitz offline" tip appear on the next visit, which looked
  like the same suggestion coming back. Closing either one now closes both
  in that browser; only clearing the site's data brings them back. If you
  closed "New in 3.1" in 3.1.4, the offline tip stays hidden too.
- **The Recovery tool has a tab icon.** It shows the IttyBitz logo in the
  browser tab instead of the browser's generic icon. The icon is built into
  the file; its security policy now allows images built into the page
  (`img-src data:`), which permits no network requests.

## For users

Nothing to do. A Recovery tool you saved from 3.1.0 or later opens every
IttyBitz file; download this one only if you want the tab icon.

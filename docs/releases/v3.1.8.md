# v3.1.8 🦕 Stegosaurus — save a QR without showing it

A small fix following [v3.1.7](v3.1.7.md). The cryptography of the app and
the Recovery tool is unchanged.

## Changes

- **Download PNG no longer needs Reveal.** For a seed phrase (Standard or
  Compact SeedQR) or a decrypted text, Download PNG used to stay greyed
  out until the QR was revealed, so saving it meant showing it on screen
  first. The image is drawn on a separate canvas that is never displayed,
  so the QR in the window now stays blurred while you save it. Reveal is
  only for showing the QR, for example to scan it with a wallet's camera.
  After a download the app still reminds you to store the image as
  carefully as the secret itself.

## For users

Nothing to do. A Recovery tool saved from 3.1.0 or later opens every
IttyBitz file.

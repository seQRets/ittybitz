# v3.1.1 🦕 Stegosaurus — telling people about Argon2id

A follow-up to [v3.1.0](v3.1.0.md), which switched new files to Argon2id key
derivation. The cryptography is unchanged from v3.1.0; this release makes
the change visible on the site itself, not just in the release notes.

## Changes

- **A "New in 3.1" notice on the app.** The top of the page now says that
  IttyBitz protects passwords with Argon2id, a stronger, memory-hard key
  derivation, and that files encrypted from now on open with the 3.1
  Recovery tool or later, with a link to download it. It stays until you
  dismiss it, and the offline-download tip waits until then, so the page
  never shows two banners at once.
- **The Recovery tool says what it opens.** Its subtitle now reads "Opens
  files from every version of IttyBitz, including 3.1 and later."
- **Clearer feature cards.** The encryption card is now titled
  **Argon2id + AES-256** and marked **New in 3.1**. The recovery card no
  longer speaks of the website being gone; it says the tool opens your data
  with no network and no need for this site.
- **README brought up to date.** It now asks anyone who saved a Recovery
  tool before 3.1 to replace it, describes the secret-text blur as it works
  today, mentions that the Argon2id working memory is wiped, and explains
  that the Recovery tool's Argon2id block is generated by the build. The
  Recovery README carries the same replacement note.

## For users

If you saved the Recovery tool before 3.1, download the new one and keep it
with your encrypted files. Existing files are unaffected.

# v3.1.7 🦕 Stegosaurus — Compact SeedQR

A feature and layout release following [v3.1.6](v3.1.6.md). The encryption
of the app and the Recovery tool is unchanged.

## Changes

- **Compact SeedQR.** When a decrypted text is a 12- or 24-word BIP-39
  seed, the QR window offers **Standard** and **Compact**. Compact SeedQR
  holds the seed's raw entropy (16 or 32 bytes) as a binary code, so it is
  smaller: 21×21 instead of 25×25 for 12 words, 25×25 instead of 29×29 for
  24. Fewer devices read it than Standard, so check that yours does. The
  window always opens on Standard, and a downloaded image is named
  `ittybitz-compact-seedqr.png`. Seeds of other lengths offer Standard
  only. The test suite checks Compact SeedQR against the published BIP-39
  test vectors.
- **A shorter QR window, with the QR the same size.** Close is a boxed X
  in the top-right corner instead of a full-width button, the line that
  repeated the format and word count is gone, and the description and the
  warning fit on one line each. The Support window gets the same X.
- **Results come into view.** On a short screen, the result (or the
  message) after Encrypt or Decrypt could land below the bottom of the
  window, as if nothing had happened. The page now scrolls just far enough
  to show it, and does not move when it is already visible. Systems set to
  reduce motion jump instead of scrolling smoothly.
- **A smaller header.** The logo sits beside the IttyBitz title instead of
  above it, so the form starts higher on the page.
- **The version number links to its release.** In the app's footer and at
  the bottom of the Recovery tool, the version opens that version's release
  page, which has its notes and `SHA256SUMS.txt`. The checksum is not shown
  inside the app: a file cannot contain its own hash, and a hash a page
  shows about itself proves nothing, since a tampered copy would show the
  expected one. See *Verify your download* in the README.

## For users

Nothing to do. A Recovery tool saved from 3.1.0 or later opens every
IttyBitz file.

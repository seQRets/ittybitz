# v3.0.17 🦕 Iguanodon — clearer words on the emergency card

A wording release, following [v3.0.16](v3.0.16.md). The cryptography,
container format, wordlist, and self-tests are untouched; the Recovery
tool's decryption core is byte-identical to every release since v2.9.0.

## Changes

The printed emergency card's instructions were rewritten.

- **Step 1** no longer speaks of the website being "gone". It says to open
  ittybitz.app, and if the website is not available, to open the IttyBitz
  Recovery tool instead, which runs in any browser, even offline, and can be
  downloaded from the project page.
- **Step 2** names the screen to use (**Decrypt Text**) and lists the ways to
  enter the encrypted text: copy and paste it from a digital copy of the
  card, scan the QR code with a phone camera, or type it as printed.
- **Step 3 always says whether a key file is needed.** A card made without a
  key file now says "No key file is needed", so nobody goes looking for one
  that was never used. A card made with one still identifies it by its
  fingerprint, never its name. The aside that the password "was kept
  separately by the person who made this" is gone.
- **The footer** no longer suggests the card can be lost or copied without
  harm. It now says that the QR code and encrypted text reveal nothing about
  the secret hidden beneath.
- The README's description of the card was updated to match.

## For users

Nothing to do. Cards printed with earlier versions still work; reprint one if
you would like the new wording.

## v 2.0.0 🔑 Lockdown — Security Audit, PWA & Zero External Requests

### 🔍 Independent Security Audit
- Full codebase security review with 12 findings documented in [`SECURITY-AUDIT.md`](SECURITY-AUDIT.md)
- All actionable findings addressed in this release

### 🔒 Security Hardening (Backward-Compatible)
- **Eliminated Google Fonts** — removed all external network requests (`fonts.googleapis.com`, `fonts.gstatic.com`); switched to system font stack. The app now makes zero outbound requests, matching the "nothing leaves your browser" promise
- **Format version header** — encrypted output now includes an `IBTZ\x01` magic header, enabling future format evolution and better error messages. Decryption auto-detects legacy (headerless) files, so **all existing encrypted data still decrypts without issue**
- **Removed `Math.random()` from `secureErase`** — the CSPRNG fallback path no longer uses a predictable RNG; falls back to zero-fill instead
- **Error message sanitization** — switched from keyword matching to an explicit allowlist of safe messages, preventing potential leakage of Web Crypto API internals
- **Honest documentation** — replaced misleading FIPS 140-2 / NSA Suite B / GDPR certification claims with accurate "uses FIPS-approved algorithms" language; memory clearing described as best-effort (limited by JavaScript GC)

### 📱 Progressive Web App (PWA)
- **Installable** — add IttyBitz to your home screen or desktop for a native app experience
- **Fully offline** — hand-rolled service worker precaches the app shell; after first visit, works with no network connection at all
- **Zero new dependencies** — service worker is ~70 lines of vanilla JS, no `next-pwa` or Workbox

### ⚡ Performance
- **PNG → WebP migration** — all image assets converted to WebP (~72% smaller: 170KB → 46KB total)
- **Removed unused config** — stripped `placehold.co` remote image pattern from `next.config.js`

### 🧹 Housekeeping
- Synced version number across `package.json`, UI footer, and service worker cache key
- Clipboard auto-clear toast now accurately reflects best-effort behavior
- Added future version detection — files from newer IttyBitz versions show a clear "please update" message instead of a confusing decryption failure

> ⚠️ **Full backward compatibility** — encrypted files from all previous versions decrypt without issue. The new format header is only added to newly encrypted output; decryption transparently handles both old and new formats.

# v3.0.14 🦕 Iguanodon — key files named by their fingerprint

A small follow-up to [v3.0.13](v3.0.13.md). The cryptography, container
format, wordlist, and self-tests are untouched; the Recovery tool's
decryption core is byte-identical to every release since v2.9.0.

## Changes

- **Generated key files carry their fingerprint in the file name.** A new
  key file now downloads as `ittybitz-key-[0e64cc39].bin` rather than
  `ittybitz-key.bin`, so the file on your disk can be matched to the
  fingerprint IttyBitz shows when you pick it. Generating a second key no
  longer produces a confusing `ittybitz-key (1).bin`.
- **Key-file fingerprints are shown in square brackets**, for example
  `fingerprint [0e64cc39]`, both where the key file is picked and in the
  notice after generating one.
- **No more advice to keep the key file with your password.** The notice
  after generating a key file used to say to keep the two together. Kept
  together, one lost bag gives up both. The notice now simply says that both
  are needed to decrypt.

## For users

Nothing to do. Existing key files keep working under any name; only newly
generated ones get the new name.

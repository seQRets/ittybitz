## v2.9.2 🦕 Archaeopteryx — Recovery app polish

Two small improvements to the standalone Recovery app, found while running the full encrypt/decrypt matrix through both apps. **Cryptography is unchanged** — `src/lib/crypto.ts` untouched, and the Recovery decrypt core is byte-identical to prior releases, so all 32 historical ciphertexts still pass through it (70/70).

**If you keep a copy of the Recovery tool, download it again** — this release replaces it. The README and `Recover/` links point at this version.

### 🔑 The key file now clears when you switch tabs

The key-file input sits outside the File/Text panes and applies to whichever mode you decrypt in — so a key file selected for one secret stayed selected when you switched tabs, and would then be applied to the next secret. The result was a "password or key file is wrong" failure on data that was actually fine, with no obvious cause.

Switching between **Decrypt a File** and **Decrypt Text** now clears the key file. (The password is deliberately left in place; only the key file clears.) Verified end-to-end: select a key file, switch to Text, decrypt a no-key-file secret with no manual clearing — it now succeeds.

### 🔗 Simpler footer, working link

The footer previously pointed at *"this file's source — `view-source:` to read it"* (which browsers refuse to open from a page), and an earlier revision had grown an on-page block of byte-level format and key-derivation detail. That's removed. The footer now simply links to **github.com/seQRets/ittybitz** — a visible, copy-pasteable URL — for anyone who wants the technical reference.

### Verified
- Full file matrix through the live UI of both apps: encrypt/decrypt with and without a key file, plus the cross-app path (files encrypted in the main app, decrypted in the Recovery app), plus text round-trips with unicode. Correct pairings round-trip; mismatched pairings fail as they should.
- Decrypt core byte-identical, recovery file byte-identical through the build.
- Typecheck, production build with CSP hashes and zero residual `unsafe-inline`, `npm audit` clean.

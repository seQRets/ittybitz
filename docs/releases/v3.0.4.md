# v3.0.4 🦕 Iguanodon — CSP hardening, anti-framing, published checksums

A security-hardening release, building on [v3.0.3](v3.0.3.md). No user-facing
behaviour changes, and the cryptography, container format, wordlist, and
self-tests are untouched.

## Changes

- **Hash-pinned Content-Security-Policy.** Both shipped files now pin every
  inline `<script>` block as a `script-src 'sha256-…'` source instead of
  `'unsafe-inline'`. The browser executes only those exact blocks and refuses
  to run any injected inline script (hash mismatch). Every other directive is
  unchanged — including `default-src 'none'`, `connect-src 'none'`, and
  `style-src 'unsafe-inline'`.
- **Anti-framing guard.** Both files refuse to initialize if they detect they
  are embedded in a frame (`window.top !== window.self`, caught for the
  cross-origin case), showing a plain "open it directly" message instead. A
  `<meta>` CSP cannot set `frame-ancestors`, so this JS check is the mechanism.
  (The `default-src 'none'` policy also blocks the pages from framing anything.)
- **Published checksums.** `SHA256SUMS.txt` now ships as a release asset
  alongside `ittybitz.html` and `ittybitz-recovery.html`. See
  [**Verify your download**](https://github.com/seQRets/ittybitz#-verify-your-download)
  in the README for the `sha256sum` / `certutil` commands.
- **Maintenance tooling.** `scripts/update-csp-hashes.mjs` (plain Node, zero
  dependencies) recomputes the inline-script hashes, rewrites both files' CSP
  in place, and regenerates `SHA256SUMS.txt`. It is idempotent and runs
  automatically as part of `npm run build`.
- **SECURITY-AUDIT.md** gained an addendum mapping the v2.8.1 (Next.js) audit
  onto the v3 single-file architecture: the PBKDF2-vs-Argon2id tradeoff still
  applies (crypto unchanged); the Next.js, CI, and bundle findings are obsolete.

## For users

Nothing to do. Existing `.ibitz` files and encrypted text decrypt exactly as
before. If you keep a saved offline copy, you can now verify it against the
`SHA256SUMS.txt` attached to this release.

# v3.0.1 🦕 Iguanodon — favicon, mobile footer, and a gentle PWA migration

A small follow-up to [v3.0.0](v3.0.0.md). The cryptography and the recovery tool are unchanged.

## Changes

- **Inline favicon.** The IttyBitz key mark now appears in the browser tab, embedded as an inline `data:` SVG — so the page still loads **zero external resources** and "Save Page As" still produces one self-contained file. (The `Content-Security-Policy` now allows `img-src data:`, which permits only inline images, never a network fetch.)
- **Centered footer on mobile.** On narrow screens the footer rows are now centered instead of left-justified.
- **Gentle migration for the old PWA.** People who installed a pre-3.0 version still have a service worker on their device. This release ships a **minimal migration worker** that replaces the old one on the next online launch:
  - **online** → it passes through to the network, so the installed app always loads the current single-file IttyBitz;
  - **offline** → instead of the old cached app, it shows a short "IttyBitz is now a single file — download it for offline use" page, moving people onto the downloadable file;
  - it deletes the old caches, so it can never serve a stale copy.

  The app itself (`site/index.html`) registers **no** service worker, so no *new* visitor ever gets one — this only retires the installs that already exist, and can be removed once they age out. A one-time, dismissible in-app banner also nudges anyone who opens the installed app while online.

## For users

Nothing to do. If you use the installed app, the next time you open it online it will quietly switch to loading the single-file version, and it will point you to downloading the file for offline use. Everything you have encrypted still decrypts exactly as before.

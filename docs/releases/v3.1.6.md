# v3.1.6 🦕 Stegosaurus — a calmer form

A layout and polish release following [v3.1.5](v3.1.5.md). The cryptography
of the app and the Recovery tool is unchanged.

## Changes

- **The form reads top to bottom.** Secret, then password, then **I have
  saved this password somewhere safe** on the left of one line with **Use
  key file** on its right, then the Encrypt button, then the result. The
  same order applies to Decrypt.
- **Encrypt is greyed out until the box is ticked.** The box unticks
  whenever the password changes. After an encryption the line stays in
  place, greyed out, and becomes active again as soon as the next one
  starts (a file chosen, a secret or password typed).
- **Fewer messages.** The "save this password" warning is gone (the
  checkbox asks the same thing), and so are "Text encrypted…", "Decrypted
  successfully. Click the eye…" and the clipboard notice. A new result is
  marked instead by a green outline that pulses twice around its buttons
  and then fades; a copy button shows a green check and "Copied" for a
  moment. Screen readers still hear every message. The clipboard is still
  cleared after 60 seconds.
- **Nothing jumps.** The File and Text panes are the same height, in the
  app and the Recovery tool, so switching between them no longer moves the
  rest of the page; the Clear link sits inside the drop zone's corner; a
  valid seed phrase's fingerprint appears on the label's line instead of
  adding one below the box; and an old result clears as soon as new input
  starts, so it is never mistaken for the result of the new secret.
- **Gentle motion.** Hover effects, state changes and anything that
  appears take 175 ms instead of snapping. Blurring a secret stays instant,
  so typed or decrypted text never shows for a moment. Systems set to
  reduce motion get none of it.
- **Shorter feature cards:** an icon and a headline each. The download
  links in them duplicated the ones in the hero and the footer, so they
  are gone.
- **Recovery tool:** the same 175 ms motion and equal-height panes; an old
  result clears when new input starts; and its decrypted text is blurred
  instantly (it used to fade into the blur over about 150 ms, briefly
  readable).
- When encrypted text is too long for a QR code, the app no longer offers
  one in its message.

## For users

Nothing to do. A Recovery tool saved from 3.1.0 or later opens every
IttyBitz file.

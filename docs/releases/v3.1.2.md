# v3.1.2 🦕 Stegosaurus — build it yourself in five minutes

A housekeeping release, following [v3.1.1](v3.1.1.md). The app and the
Recovery tool work exactly as in v3.1.1; only their version labels change.
It exists so that this release's **Source code (zip)** carries the simpler
build tooling the README now describes.

## Changes

- **Step-by-step build instructions.** The README's build section now walks
  through installing Node.js, downloading the source, opening a terminal on
  Mac or Windows, and running one command, with no technical background
  assumed. A separate section for contributors covers the details.
- **The build says whether it matches.** `npm run build` now ends with a
  plain sentence saying whether the files you built are byte-for-byte
  identical to the published ones in `SHA256SUMS.txt`.
- **Node.js is the only requirement.** `npm run dev` now uses a tiny
  built-in server instead of Python. `npm run test:crypto` checks the
  Node.js version first and, on anything older than 24.7, says what to
  install instead of failing with a cryptic error.
- **Builds reproduce on Windows too.** A new `.gitattributes` keeps line
  endings identical on every platform, so a Windows checkout builds the same
  bytes as everyone else.
- **Tidier repository.** Dependabot no longer watches npm, which IttyBitz
  does not use; `src/lib/` explains what its reference files are for; the
  README's contributor notes are corrected (the full list of build parts,
  what the tests prove, and which edits need a rebuild) and include a map of
  the repository.

# v3.1.3 🦕 Stegosaurus — easier to download the app

A small follow-up to [v3.1.2](v3.1.2.md). The cryptography and the Recovery
tool's behaviour are unchanged.

## Changes

- **A "Download IttyBitz" button at the top of the app.** It sits under the
  tagline, marked "one file · runs offline", so the way to keep IttyBitz on
  your own computer is the first thing you see. It is hidden when you are
  already running a downloaded copy.
- **The client-side card links the download too.** It now says "Download it
  once and it runs offline, too", with a **Download IttyBitz app** link.
- **Fewer repeated Recovery-tool links.** The page offered four ways to get
  the Recovery tool and one way to get the app. "Recoverable without us" in
  the hero is now plain text; the Recovery card, the New in 3.1 notice and
  the footer still link the Recovery tool, so the app now has three download
  links and the Recovery tool two.
- **README: removed the link to an older external security report,** which
  described a previous version of IttyBitz. The section is now titled
  "Audit and transparency" and points to the in-repo audit, with its note
  about which version it covers.

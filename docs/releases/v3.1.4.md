# v3.1.4 🦕 Stegosaurus — crisper look

A visual follow-up to [v3.1.3](v3.1.3.md). The cryptography and behaviour of
the app and the Recovery tool are unchanged.

## Changes

- **No more glow.** The amber glow around the logo, the glow under the
  selected Encrypt/Decrypt tab and under the main Encrypt/Decrypt button,
  and the warm haze painted behind the top of the page (with a faint red
  one in the corner) are gone, in both the app and the Recovery tool. The
  page now sits on plain black, and every edge is sharp.
- **Calmer button hover.** The main button no longer lifts and glows when
  you point at it; it brightens slightly instead.
- **Consistent link colour in the Recovery tool.** The two links at the
  bottom of the Recovery tool used the browser's default blue with an
  underline; they now use the same orange as every other link.
- **Updated README image,** showing the page as it looks now.

Nothing to do.

# v3.0.13 🦕 Iguanodon — readable hint text

A one-colour follow-up to [v3.0.12](v3.0.12.md). The cryptography, container
format, wordlist, and self-tests are untouched; the Recovery tool's
decryption core is byte-identical to every release since v2.9.0.

## Changes

- **The faint grey now meets WCAG AA contrast.** The password hint ("min 24
  chars, upper, lower, number, symbol") measured 3.9:1 against the card,
  under the 4.5:1 that accessibility guidelines ask of text that size. The
  grey is now `#838391` (5.2:1), still quiet but readable. The same fix
  applies to the Recovery tool's hint text and "(only if one was used)"
  label, and to the offline notice shown to users of the old installed app.
  Found by Dean Rie (#56). No file changes size.

## For users

Nothing to do. Existing `.ibitz` files and encrypted text decrypt exactly as
before.

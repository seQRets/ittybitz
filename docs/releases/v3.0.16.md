# v3.0.16 🦕 Iguanodon — a one-page card that tells the truth about the key file

Follows [v3.0.15](v3.0.15.md). The cryptography, container format, wordlist,
and self-tests are untouched; the Recovery tool's decryption core is
byte-identical to every release since v2.9.0.

## Fixes

- **The emergency card is laid out for one US Letter page.** It used to
  spill onto a second page, in serif type, with no paper size of its own. It
  now asks the printer for US Letter with half-inch margins (printing the app
  itself keeps the printer's own paper size) and uses the whole page: the
  title at the top, the note at the bottom, and the QR, the encrypted text and
  the steps spaced evenly between. Everything is in the app's sans-serif: a
  24 pt title, 14 pt steps, 11 pt notes, and the encrypted text at 12 pt for
  typical lengths. The 7 cm QR sits in a rounded frame with 5 mm of white
  around it. Very long encrypted texts step the type down so that even the
  largest text a QR can hold still prints on one page. Page margins stay
  white when background graphics are printed.
- **The card is right about the key file.** Whether a key file is needed is
  now recorded when the text is encrypted. Previously the card asked the
  key-file switch at the moment of printing, so turning the switch off after
  encrypting printed a card that never mentioned the key file the text needs,
  and the reverse could claim a key file that was never used.
- **The card no longer names the key file.** It used to print the file's
  name, telling anyone who found the card exactly which file to look for. It
  now gives the key file's fingerprint, for example `[6cfeeb3a]`, which the
  owner can recognise and a finder cannot use. The Recovery tool now shows a
  key file's fingerprint when it is selected, just as the app does, so the
  card works with either.
- **Arrow keys no longer wipe what you typed.** On the Encrypt / Decrypt and
  File / Text tabs, arrow keys now only move the focus. Enter, Space or a
  click switches. Before, a single stray arrow key switched mode and cleared
  a half-typed secret and password.
- **Download PNG works straight away for encrypted text.** The button stayed
  disabled until Reveal, even though the QR holds only ciphertext that is
  already on screen and could be printed without revealing. It still waits
  for Reveal when the QR holds decrypted text or a seed.
- **Key-file bytes are wiped after fingerprinting.** The copy read to show a
  key file's fingerprint, and a freshly generated key file once downloaded,
  are now erased like the rest of the key material.
- **Password managers.** Decrypt password fields no longer ask password
  managers for a *new* password, which made some offer to generate one that
  could never decrypt. Encrypt mode still does.

## For users

Nothing to do. Existing `.ibitz` files and encrypted text decrypt exactly as
before. Cards printed with earlier versions that named a key file still
work; consider reprinting them so the file name is no longer on paper.

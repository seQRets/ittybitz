# v3.0.2 🦕 Iguanodon — seed fingerprint, UX polish

A round of interface improvements on top of [v3.0.1](v3.0.1.md). The cryptography and container format are unchanged, and everything is still gated in CI (91 checks).

## New: BIP-39 master fingerprint

When a valid BIP-39 seed phrase is detected, IttyBitz now shows its **BIP-32 master fingerprint** — the same identifier your hardware wallet displays (e.g. Coldcard, SeedSigner, Sparrow), so you can confirm you have the *right* seed:

- **Encrypting text** — type a seed and, alongside the green "valid seed" border, the fingerprint appears beneath the box, live.
- **Decrypting text** — a decrypted seed shows the fingerprint under the result and directly beneath the SeedQR.
- It is computed the full, correct way (BIP-39 → seed → BIP-32 master key → secp256k1 → RIPEMD-160), implemented locally with no network, and gated in CI against the canonical test vectors. It is a one-way public identifier, so it shows even while the secret stays blurred — verify the seed without exposing it.

## Interface

- **QR modal now shows the QR immediately, blurred**, instead of a blank white box (which looked broken). The **Reveal** button un-blurs it and enables the PNG download.
- **SeedQR modal is much shorter** — smaller QR, tighter spacing, and a hard height cap so it never fills the screen. The hardware-wallet compatibility list was removed (it would only go stale as more wallets adopt SeedQR).
- **Result and secret-text controls are now laid out horizontally** in the top-right corner and no longer overlap — previously the reveal/copy/QR buttons stacked in one spot, hiding the reveal eye behind the QR button.
- **Reveal (eye) icons are now action-based**: a clear eye when hidden (click to reveal), an eye with a slash when visible (click to hide).
- The **secret-text field uses a readable sans font** (monospace is kept only for the base64 on the decrypt side), with room so text never hides behind the buttons, and it gained a **copy button**.
- **A "Download to run offline" banner** now appears for visitors of the hosted site (hidden once you are running a saved local copy or the installed app), and the migration/offline messaging clarifies the downloaded file **opens and runs right in your browser** — no separate app to install.
- Inline favicon and centered banner text.

## For users

Nothing to do. Existing `.ibitz` files and encrypted text decrypt exactly as before.

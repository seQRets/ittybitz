# v3.1.9 🦕 Stegosaurus — a quieter key file

A layout release following [v3.1.8](v3.1.8.md). The cryptography of the app
and the Recovery tool is unchanged.

## Changes

- **A slim key-file box.** "Use key file" now opens one row instead of a
  large drop zone, an "or" divider and a full-width button: 60 px instead
  of 237 px on a desktop screen. **Generate** sits beside it (below it on
  a phone). A chosen file's name is on the first line and its fingerprint
  on the second, so the fingerprint is never cut off on a narrow screen;
  Clear is at the row's right end. The Recovery tool's key-file box is the
  same slim row.
- **No key-file notice.** Generating a key file no longer prints a
  paragraph under the button: the browser's download shows the file, and
  its name carries the fingerprint. To use a generated key file, choose
  it in the box, as before.
- **A quieter confirmation for files.** After a file is encrypted or
  decrypted, the button turns green with a check ("Encrypted" or
  "Decrypted") for a moment instead of showing "downloaded as …" below
  it. The same applies to several files when every one succeeds; if any
  fails, the summary is shown as before. Text results keep their pulsing
  outline. Screen readers still hear the full message. The Recovery tool
  does the same.
- **The form starts over after a success.** Along with the password, the
  chosen file and key file are cleared; the key-file box stays open, so
  nothing on the page moves, and the next job asks for a key file until
  one is chosen or the switch is turned off. After a failure (a wrong
  password, say) the file and key file stay, so only the password needs
  retyping.
- **No feature cards on phones.** The three cards under the form show on
  wider screens only.

## For users

Nothing to do. A Recovery tool saved from 3.1.0 or later opens every
IttyBitz file.
